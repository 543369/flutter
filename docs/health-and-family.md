# 健康档案、家庭周报与照护权限

本阶段只实现权益和功能，尚未接支付。开发预览默认开放高级权益；关闭 `PETCARE_BENEFITS_PREVIEW` 可验证免费版边界。

## 功能与入口

| 功能 | 入口 | 基础版 | 高级权益 |
| --- | --- | --- | --- |
| 健康档案 | 宠物 → 宠物详情 → 健康档案 | 疫苗、驱虫、用药、过敏、体重、就诊的新增、详情、编辑、删除和分类查询 | 长期体重趋势、批量归档 |
| 健康图片附件 | 健康记录编辑 | 每条最多 2 张，与家庭基础 100 MB 空间共用 | 每条最多 12 张，与高级家庭空间共用（体验 1 GB） |
| 家庭周报 | 家庭 → 家庭周报与多宠统计 | 本周完成率、遗漏、多宠汇总、成员分工 | 查看历史周、近 8 周多宠趋势 |
| 成员角色 | 家庭 → 家人与照护权限 | 管理员、家庭成员 | 临时照护者、自定义模块权限、到期时间 |
| 照护分工 | 安排详情 → 指定照护人 | 指定或清除负责人 | 同基础版 |

健康记录保存标题、分类、发生日期、详细说明、体重（仅体重类型）、图片附件、文件夹、创建及修改时间。用药剂量、疗程、医院和医嘱等信息可填写在说明中。当前附件支持照片，不包含 PDF 或其他文件上传；健康记录不会自动生成诊断或用药建议。

## 权益与容量

基础健康文本记录没有会员门槛。服务端在家庭锁和事务内计算图片实际解码字节数，健康附件与档案照片、回忆照片共用额度。超额写入返回 `413 STORAGE_LIMIT_EXCEEDED`，整个写入回滚。

家庭权益页的已用空间和图片总数均包含健康图片附件；健康记录上传区域也明确提示共用额度。健康附件没有独立空间池，删除附件后释放对应的家庭额度。每条记录的附件数量上限与家庭总空间上限分别校验。

权益到期不删除旧照片和记录，也不阻止缩减图片数量或不增加占用的修改。高级体重趋势按月计算已记录体重的平均值、最小值、最大值和测量次数，缺失月份不估算。批量归档一次最多 100 条，支持改文件夹或移出文件夹；任一记录不属于当前宠物时，整批回滚。

## 周报口径

- 自然周从周一开始，使用设备时区。基础版可查看当前周，高级版可选择历史周并查看截至所选周的近 8 周。
- 分母为截止当前时间（历史周为周末）已经到期且未取消的安排；未来安排不算遗漏。没有到期安排时完成率为空，不显示为 0% 或 100%。
- 分子取截止时每项安排最后一次操作为完成的数量。撤销、重新完成不会重复累计；历史周之后才补做的安排不会改写该周末的状态。
- 遗漏 = 到期安排 − 完成安排，列表最多显示最早 50 项。可到全部安排处理。
- 成员分工分别展示当前分配数量与实际完成人完成数量，不能将它们混为同一个指标；历史分配关系未做快照，统计使用当前负责人。
- 仅基于当前保留的宠物和记录；删除、取消或事后新增历史安排会影响重新生成的结果。

## 角色与权限

管理员拥有全部权限，负责邀请和调整角色；家庭成员默认可操作照护、健康档案、回忆录、宠物以及统计与导出，不能修改角色或发邀请。临时照护者默认只有照护操作权限，必须指定未来的到期时间。

高级自定义权限按五个模块设置：`CARE`、`HEALTH`、`MEMORIES`、`PETS`、`REPORTS`。宠物管理权限包含删除宠物及其关联记录；授权时应一并考虑。这里是模块级权限，当前不包含逐宠物、逐记录或读写分离的授权。有效成员仍可查看基础家庭首页和成员名单；生日、手机号仍只对账号本人开放。

服务端在每次家庭操作时检查角色、模块权限及到期时间。角色权限的限制在会员到期后继续保留，不会因降级而扩大访问范围。权限到期后不能继续访问家庭数据，但可以退出家庭或登录账号；客户端会清除首页缓存和已同步的家庭提醒，并提供联系管理员/退出入口。

家庭至少保留一位管理员。最后一位管理员不能降级、退出或在仍有其他成员时删除账号；应先将管理员身份授予另一人。成员退出后共享宠物与记录留在原家庭，其账号进入新的空家庭，原任务分配清除。

普通邀请码仍为 24 小时、单次使用；临时邀请同时校验照护到期时间，过期不能加入。更改成员角色会撤销本家庭尚未使用的邀请码。

## 数据与接口

### 就诊与寄养前导出

入口：健康档案右上角「时间线与导出」。可选择就诊或寄养用途，以及发生日期范围；默认全部记录，按发生日期、创建时间和记录 ID 从早到晚排列。

- PDF：宠物基本信息、分类记录数量、交接说明和完整记录时间线。短记录连续排版，长说明自动跨页，生成后先预览再保存。
- CSV：UTF-8 BOM 编码，包含六类记录、原始说明、体重、附件数量、文件夹及创建/修改时间，支持 Excel 中文显示及多行单元格；可能被解释为公式的文本添加保护前缀。
- 两种格式均不读取个人资料中的账号和手机号。健康附件只列数量，不打包图片文件。所选范围不等于完整健康史，历史过敏/用药记录不自动判断为当前状态。
- 基础版可使用此导出，但角色需同时具备健康档案及统计与导出权限。桌面端 CSV 使用保存位置选择器，手机使用系统文件分享；PDF 使用现有预览和保存功能。

`GET /api/pets/{petId}/health/timeline?from=YYYY-MM-DD&to=YYYY-MM-DD` 返回同一事务中读取的宠物信息与记录；日期参数可省略，包含边界日期。

- `GET/POST /api/pets/{petId}/health`，`GET/PATCH/DELETE /api/pets/{petId}/health/{recordId}`。
- `GET /api/pets/{petId}/health/trend`，`POST /api/pets/{petId}/health/organize`。
- `GET /api/family/weekly?start=YYYY-MM-DD&zoneId=Asia/Shanghai&trends=true`。
- `GET /api/family/members`，`PATCH /api/family/members/{memberId}`，`POST /api/family/leave`。
- `POST /api/invites` 可选 `role`、`permissions` 和 `expiresAt`；不传时创建普通成员邀请。
- `PATCH /api/tasks/{taskId}/assignment` 接收 `memberId`，null 表示清除；只能指定同家庭、有照护权限且未过期的成员。

`V12__health_and_household_roles.sql` 创建健康记录及附件表，增加角色和负责人字段。历史家庭按账号 ID 的稳定顺序选择一位管理员，其余转为普通成员；新独立家庭默认管理员。任务负责人通过服务端家庭校验，并在退出/删除账号时清除，新增列使用在线方式，不重建已有照护历史。

本机迁移时检测到 12 条原有、宠物关联缺失的照护任务。本次未删除或修改这些历史记录；失败迁移只回退了本次新增字段和失败标记，再执行修正版。正式部署前应另行检查现有数据完整性。

## 验证

- `HealthAndRolesTests`：免费录入、趋势权益、跨家庭拒绝、到期、最后管理员和周报统计。
- `scripts/health_family_smoke_test.py`：真实 HTTP 六类记录、附件、批量回滚、邀请、权限、任务分工与周报；临时账号自动清理。
- `scripts/health_free_smoke_test.py`：专用测试 API 需关闭体验并设基础额度为 150 字节，验证免费附件数、空间超额回滚、高级权益与释放容量。
- `mobile/test/health_family_test.dart`：健康记录保存重试与详情、周报和临时权限编辑。
- `mobile/tool/health_family_visual_qa_test.dart`：新增页面中文截图检查。
