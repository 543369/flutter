# 个人资料

入口：家庭 → 个人资料，或者点击「一起陪伴的人」中的本人卡片。

- 详情展示昵称、登录账号、生日、手机号、账号创建时间和账号 ID。
- 点击「编辑资料」修改昵称，通过日历选择生日，并填写手机号；生日和手机号可以清除。
- 生日不能晚于今天；账号和创建时间不允许在资料表单修改。
- 手机号仅为未验证的资料字段，不作为登录、短信认证或密码找回凭据；生日和手机号仅通过本人的资料接口返回，不在家庭成员列表中公开。
- 注册时昵称选填；留空由服务端根据设备语言/地区随机生成。支持简体中文、繁体中文、日语、韩语，其余使用英文昵称，加随机数字。昵称不要求唯一，身份始终由账号 ID 区分。
- 注册成功会提示「家庭 → 个人资料 → 编辑资料」修改路径；已有自定义昵称不会自动重置。
- Apple 首次注册同样生成默认昵称，资料显示 Apple ID 和内部账号 ID，不暴露 Apple subject。

接口：`GET /api/profile` 与 `PATCH /api/profile`，均要求登录。保存字段为 `name`、`birthDate`（YYYY-MM-DD 或 null）、`phone`（字符串或 null）。当前表单完整提交这三个字段。

迁移 `V11__personal_profiles.sql` 为账号增加生日、手机号及创建时间。旧账号未曾记录的创建时间保留为空，显示「未记录」；新账号使用数据库创建时间，编辑资料不会覆盖。

验证：个人资料保存、失败重试、日期选择、身份隔离、创建时间不变、服务端校验、默认昵称注册与中文详情/弹窗截图；macOS Debug 构建。
