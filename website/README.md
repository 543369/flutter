# 家庭照护官网

独立静态站点，发布目录为 `dist/`，无需安装依赖。产品代码与后台服务不参与网站部署。

## 本地预览

在仓库根目录运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory website/dist
```

打开 http://127.0.0.1:8765 。

## 启用下载

编辑 `dist/releases.json`；`null` 表示尚未发布。每个平台填入真实信息后，页面自动启用下载链接：

```json
{
  "android": {
    "url": "https://你的下载域名/petcare-0.1.0.apk",
    "version": "0.1.0",
    "date": "实际发布日期",
    "size": "实际文件大小",
    "requirements": "经过验证的系统要求",
    "sha256": "实际文件 SHA-256"
  },
  "macos": null
}
```

仅使用 HTTPS 或同源相对路径。安装包应上传到正式文件存储，不要把开发包作为正式版本发布。

## 正式上线前

- 配置真实安装包、系统要求、版本及校验值。
- 在隐私说明、使用说明、关于与支持页面补齐运营主体、有效邮箱和已确认的正式文本。
- 按最终托管方案绑定域名、启用 HTTPS，并确认面向审核人员及用户的公网访问权限。
- 页面里的照护计划和家庭面板为示例，不是真实应用截图。

## 部署

任意静态托管或 Web 服务器均可直接托管 `dist/`。`.openai/hosting.json` 记录本次 Sites 项目身份；Sites 私有预览不等同于对公众开放的正式官网。

## 页面与品牌

共 9 个页面：首页、产品功能、照护场景、使用指南、关于家庭照护、Android 下载、帮助与支持、隐私说明、使用说明。

品牌图标为 `dist/assets/logo.svg`，使用爪印、爱心和完成勾号，已用于官网导航、页脚、favicon 和下载页。移动应用图标尚未替换。

导航、页脚及内容页面由 `scripts/build_pages.py` 生成。修改该脚本或 `templates/` 中的基础内容后运行：

```sh
python3 website/scripts/build_pages.py
```

`dist/` 可直接部署，无需服务端运行 Python。当前以 Android 为主，macOS 暂缓。公开版本发布时除更新 `releases.json`，也需同步更新首页常见问题、支持页和版本动态中的发布状态文字。

第二版验证：9 页资源和锚点链接检查通过；生成脚本可重复运行；浏览器检查桌面等宽卡片、Android 下载页、390px 手机布局和折叠菜单。

官网定位已同步为“家庭照护 Family Care”：宠物与家人两套体验，新增长辈、儿童、术后／康复场景及家人逐人授权说明。宠物健康档案与家人用药执行记录分别描述；跨设备推送仍标注需正式服务配置。保留原爪印品牌资产，后续可单独更新统一标识。本地内容更新不代表已部署到公网。
